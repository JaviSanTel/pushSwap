# Libft

## Descripción 
Este es el primer proyecto oficial del currículo de 42. El objetivo consiste en programar desde cero nuestra propia librería en C, recreando el funciones esenciales de la librería estándar de C ('libc') además de otras funciones adicionales de utilidad para el manejo de memoria, cadenas de caracteres y listas enlazadas.

El objetivo principal de este proyecto es comprender a fondo el funcionamiento interno de las funciones del sistema, dominar la manipulación de punteros, la gestión manual de memoria (uso de 'malloc' y 'free') y aprender a estruturar un código limpio y eficiente. Esta librería será la base de datos y herramientas que utilizaremos en la gestión de proyectos futuros de 42.

## Instrucciones
Sistema operativo: Entornos basados en Unix. 
Compilador: 'cc' (con flags '-Wall -Werror -Wextra')
Herramientas de automatización: 'make'

Para compilar la librería completa (incluyendo tanto las funciones estándar como las de listas enlazadas), ejecuta el comando 'make' en la raíz del proyecto. El archivo de la librería estática 'libft.a' se generará automáticamente a partir de los objetos compilados.
